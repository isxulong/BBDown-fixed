BBDown-fixed v1.0.4（bat 版）
基于 BBDown 1.6.3 修复：扫码登录、凭据自动续期已修好

v1.0.4 更新：
- 3 个基础 bat 改为 UTF-8 并声明 65001 代码页：BBDown 输出的中文在任何区域设置的
  Windows 上都能正常显示（旧版 bat 是 GBK 编码、未声明代码页，只能被按 GBK 正确解码）
- 命令生成器页面显示当前版本号，随时知道自己在用哪个版本
- 生成器打开时自动检查一次更新：有新版本时页面顶部出现提示，
  点击即可打开下载页（只提示、不自动替换，用不用随你）
- EXE 界面版同批大改（固定底栏、批量进度、拖拽、分P勾选、番剧课程
  收藏夹预览、登录三态等），bat 版用法不变、只修了乱码

【这个包里有什么】
- core\ 文件夹       核心组件（BBDown.exe / aria2c.exe / ffmpeg.exe），
                     所有 bat 都在调用它，别删、不用双击里面的东西
- 3 个基础 bat        登录 / 默认下载 / 只看信息不下载
- bat下载命令生成器.html  双击用浏览器打开，生成更多场景的专用 bat
- BBDown命令使用指南.txt  零基础命令教程，想自己改 bat 就看它

【第一次用 / 从旧版升级，必看】
1. 从 v1.0.0 / v1.0.1 / v4 系列升级：解压新包后，把旧文件夹里的
   BBDown.data 手动移进 core 文件夹（如有 BBDown.refresh_token、
   BBDownTV.data 也一并移入），凭据仍然有效，不用重新登录
   （bat 版没有自动迁移，EXE 界面版才有）
2. 从 v1.0.2 / v1.0.3 升级：直接解压新包、整个文件夹替换即可，core
   文件夹里的 BBDown.data 等凭据文件保留就有效，不用重新登录
3. 从官方 1.6.3 或更早版本过来：旧 BBDown.data 已失效，先删掉，
   再重新登录一次
4. 登录方式：双击「B站下载(修改AV号) - 登录.bat」，用手机B站APP
   扫码；成功后 core 文件夹里会生成 BBDown.data，以后不用再扫
   （凭据到期前会自动续期）

【下载视频】
改 BV 号 → 双击对应的 .bat，就这么简单。
需要合集选集、批量下载、指定清晰度等更多场景时：
打开「bat下载命令生成器.html」，粘贴链接、按提示点几下，
就能生成专用 bat——文件名里自带 BV 号 / ID，不会分不清是哪个任务的。
想自己手写命令，打开《BBDown命令使用指南.txt》，零基础照着做即可；
注意手敲命令要写成 core\BBDown.exe 开头（指南里有说明）。

【关于 UP 主主页（space.bilibili.com/xxxx）】
BBDown 本身不支持一键下载 UP 主全部投稿：把 UP 主主页喂给它，
出现的红字「暂不支持该功能」是固定提示、不是出错，同时会生成一个
「UP主名字+的投稿视频.txt」清单文件。
想批量下载：用「bat下载命令生成器.html」粘贴 UP 主主页链接，
生成两步 bat（先导出清单、再逐个下载），双击运行即可。

【关于检查更新】
生成器页面每次打开时联网检查一次新版本（只查版本号、不上传任何
信息），24 小时内不重复检查。有新版本时页面顶部出现提示，
点它打开下载页，自己决定要不要升级；断网时完全无感、照常使用。

【本版相对官方 1.6.3 的改进】
- 修复扫码登录：补上B站2026年新增的「换票」步骤，正确保存真实 Cookie
- 新增凭据自动刷新：SESSDATA 到期前自动续期，不再需要每半年手动重扫
- wbi 签名修复、固定当代 Chrome UA、启动自动获取 buvid3（降低风控概率）
- 附带 bat 下载命令生成器：粘贴链接就能生成各种场景的专用 bat，
  带版本显示与更新提示
- TV 登录、手动填 Cookie 等其他用法不受影响

【如果登录失败，怎么反馈】
把窗口里从「扫码成功」到结束的所有行复制发给维护者即可。
注意：扫码成功之后会有一行「登录成功: SESSDATA=…」，等号后面是凭据本身，
发之前请把那一行的值删掉（其余行不含凭据值）。

【其他】
- 本 exe 为自包含单文件，无需安装 .NET 运行时
- 体积比官方大是因为官方用了 Windows 专用的原生编译技术，
  跨平台编译无法使用，功能完全一致
- 想要图形界面（带视频预览卡）？去发布页下载 EXE 界面版
