BBDown-fixed v1.0.4（EXE 界面版）
基于 BBDown 1.6.3 修复：扫码登录、凭据自动续期已修好，附带图形界面

v1.0.4 更新：
- 底部操作栏固定：开始/取消、登录、进度条、状态文字常驻底部不随日志滚走；
  下载中「开始下载」原地变红变「取消下载」，不用再找另一个按钮
- 多P/多集下载显示「已完成 x/N · 正在下载：标题」，进度条按条目推进
- 粘贴链接可直接把链接拖进窗口；按回车就开始，不用点按钮
- 预览卡支持分P/选集勾选（默认全选），也能预览番剧、课程、收藏夹
- 预览没加载出来时明确提示「不影响下载」并说明原因，不再一片空白
- 登录状态用三色点显示（未登录/已登录/凭据过期），过期时按钮变「重新登录」
- 下载设置（保存位置、清晰度、编码、弹幕、多线程等）关掉再开也记得住
- UP 主主页导出投稿清单后，可直接打开清单文件夹或跳到批量生成器
- 窗口标题显示版本号，随时知道自己在用哪个版本
- 启动时自动检查一次更新：有新版本时窗口顶部出现提示条，
  点击即可打开下载页（只提示、不自动替换，用不用随你）

【这个包里有什么】
- BBDownHelper.exe   图形界面，日常下载就用它（双击即用）
- core\ 文件夹       核心组件（BBDown.exe / aria2c.exe / ffmpeg.exe），
                     界面在背后自动调用，别删、不用双击里面的东西
- bat下载命令生成器.html  双击用浏览器打开，批量下载 UP 主投稿时用它
- 登录.bat           备用登录方式（一般用不到，见下）

【第一次用 / 从旧版升级，必看】
1. 从 v1.0.0 / v1.0.1 升级：解压新包后，把旧文件夹里的 BBDown.data
   拷到新包顶层即可——首次双击 BBDownHelper.exe 时会自动把它
   移进 core 文件夹，凭据仍然有效，不用重新登录
2. 从 v1.0.2 / v1.0.3 升级：直接解压新包、整个文件夹替换即可，core
   文件夹里的 BBDown.data 等凭据文件保留就有效，不用重新登录
3. 从官方 1.6.3 或更早版本过来：旧 BBDown.data 已失效，先删掉，
   再重新登录一次
4. 登录方式：双击「登录.bat」，用手机B站APP扫码；成功后 core
   文件夹里会生成 BBDown.data，以后不用再扫（凭据到期前会自动续期）

【日常下载】
双击 BBDownHelper.exe → 粘贴链接（BV号 / av号 / 视频页 / 合集页 / 短链都行）
→ 自动识别并显示标题和封面预览 → 勾选要下的内容 → 选保存位置 → 开始下载。
也可以先点「只解析不下载」确认信息无误，再决定下不下。
个别网络环境下预览会被 B 站接口拦住，此时预览区会显示一句「不影响下载」的说明，
照常可以下载。

【关于 UP 主主页（space.bilibili.com/xxxx）】
BBDown 本身不支持一键下载 UP 主全部投稿：粘贴 UP 主主页后出现的
红字「暂不支持该功能」是固定提示、不是出错，同时会生成一个
「UP主名字+的投稿视频.txt」清单文件。
想批量下载：打开包里的「bat下载命令生成器.html」，粘贴 UP 主主页链接，
按提示生成 bat 文件，双击运行即可（先导出清单，再逐个下载）。
界面版遇到 UP 主主页时也会直接引导你这么做。

【关于检查更新】
每次启动时联网检查一次新版本（只查版本号、不上传任何信息），
24 小时内不重复检查。有新版本时窗口顶部出现橙色提示条，
点它打开下载页，自己决定要不要升级；没有新版本或断网时完全无感。
命令生成器页面也有同样的版本显示与检查更新。

【本版相对官方 1.6.3 的改进】
- 修复扫码登录：补上B站2026年新增的「换票」步骤，正确保存真实 Cookie
- 新增凭据自动刷新：SESSDATA 到期前自动续期，不再需要每半年手动重扫
- wbi 签名修复、固定当代 Chrome UA、启动自动获取 buvid3（降低风控概率）
- 附带图形界面 BBDownHelper：粘贴链接即可下载，带标题封面预览，
  不用记命令
- 附带 bat 下载命令生成器：覆盖合集选集、批量、UP 主投稿等场景
- TV 登录、手动填 Cookie 等其他用法不受影响

【如果登录失败，怎么反馈】
把窗口里从「扫码成功」到结束的所有行复制发给维护者即可。
注意：扫码成功之后会有一行「登录成功: SESSDATA=…」，等号后面是凭据本身，
发之前请把那一行的值删掉（其余行不含凭据值）。

【其他】
- BBDown.exe 与 BBDownHelper.exe 都是自包含单文件，无需安装 .NET 运行时
- 体积比官方大是因为官方用了 Windows 专用的原生编译技术，
  跨平台编译无法使用，功能完全一致
