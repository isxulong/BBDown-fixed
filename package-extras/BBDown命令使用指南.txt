BBDown 命令使用指南（零基础版）
======================================================

在包根目录（.bat 文件所在的文件夹）手敲命令时，开头用 core\BBDown.exe，
例如 core\BBDown.exe -mt BV12Rxq6nECN；也可以先输入 cd core 回车，
进入 core 文件夹后直接用 BBDown.exe 开头。本指南的示例统一按
前一种写法（core\BBDown.exe 开头）。

一、30 秒上手
------------------------------------------------------
1. 在文件夹里找到一个名字带你要的功能的 .bat 文件
   （比如「B站下载(修改AV号).bat」）
2. 右键这个文件 → 编辑（或用记事本打开）
3. 把里面的 BV 号换成你要下载的视频 BV 号，保存
4. 双击这个 .bat 文件，等它下完

BV 号是什么：打开 B 站某个视频的网页，看浏览器地址栏，
bilibili.com/video/ 后面那一串以 BV 开头的字符就是。
例如网址是 bilibili.com/video/BV12Rxq6nECN，
那 BV 号就是 BV12Rxq6nECN。


二、每个 .bat 文件是干什么的
------------------------------------------------------
登录                手机扫码登录B站账号（第一次用先跑这个）
（默认下载）        下载视频，自动选你可用的最高画质
AUDIO               只要音频，不要画面
批量                一次下多个视频，一行一个
手动选清晰度        列出所有画质让你点序号，最省心
指定清晰度          按你写的优先顺序自动挑画质
合集选集            多集视频只下指定的几集
视频带弹幕          视频和弹幕一起下载
只看信息不下载      只列出视频信息，不真正下载
保存到指定文件夹    下载到你指定的位置，比如 D 盘


三、想自己组合：命令格式
------------------------------------------------------
所有 .bat 文件里其实就一行核心命令，格式是：

    core\BBDown.exe [开关] BV号

（如果你已经 cd core 进了 core 文件夹，开头就写 BBDown.exe。）

开关可以叠加，写几个都行。常用的有：

  -mt               多线程下载，速度快（建议都带上）
  -ia               交互式选画质，运行后按提示输入序号
  -q "画质1,画质2"  按优先顺序挑画质（名字要和视频页面一致）
  -p 3-5            只下第3到第5集（也能写 -p 8、-p 1,2、-p ALL）
  --audio-only      只要音频
  --video-only      只要画面（无声）
  -dd               连弹幕一起下载
  -info             只看信息不下载
  --work-dir "路径" 下载到指定文件夹
  --sub-only        只要字幕
  --cover-only      只要封面
  --danmaku-only    只要弹幕
  --save-archives-to-file   记录已下载过的视频，下次自动跳过

例子 1：下载视频并带弹幕、多线程：
    core\BBDown.exe -mt -dd BV12Rxq6nECN

例子 2：只要第 2 集的音频：
    core\BBDown.exe --audio-only -p 2 BV12Rxq6nECN

例子 3：下合集全部，并且每集之间歇 5 秒（防被限流）：
    core\BBDown.exe -mt -p ALL --delay-per-page 5 BV12Rxq6nECN


四、常见问题
------------------------------------------------------
Q：提示「你尚未登录B站账号」？
A：双击「登录」那个 bat，用手机B站APP扫码。登录一次长期有效，
   凭据会自动续期。

Q：窗口一闪就没了？
A：本套 bat 结尾都加了 pause，正常情况下窗口会停住。
   如果还是闪退，多半是把命令改错了，重新对照本指南检查。

Q：下载完没有视频文件，只有一堆零碎的？
A：确认 ffmpeg.exe 和 BBDown.exe 在同一个文件夹里
   （本压缩包里它们都在 core 文件夹），合并音视频需要它。

Q：想下 4K / 1080P高码率，结果只下到 1080P？
A：这些画质需要登录大会员账号。先扫码登录，再下载。

Q：弹幕文件 .ass 怎么用？
A：和视频放同一文件夹、保持同名，用 PotPlayer、弹弹play
   等播放器打开视频就会自动加载。

Q：怎么确认我的命令写得对不对？
A：把命令里的开关先换成 -info 跑一遍，只解析不下载，
   能正常列出信息就说明没问题。
